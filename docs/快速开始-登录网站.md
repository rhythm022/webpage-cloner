# 快速开始：克隆需要登录的网站

本指南帮助你在 5 分钟内学会克隆需要登录的网站。

## 🚀 三步搞定

### 步骤 1：选择登录方式

根据你的情况选择一种方式：

| 方式 | 适用场景 | 难度 | 推荐度 |
|------|---------|------|--------|
| **Cookie** | 大多数网站 | ⭐⭐ | ⭐⭐⭐⭐⭐ |
| **用户数据目录** | 复杂认证 | ⭐⭐⭐ | ⭐⭐⭐⭐ |
| **手动登录** | 有验证码 | ⭐ | ⭐⭐⭐ |

**推荐**：如果不确定，使用 Cookie 方式。

### 步骤 2：获取登录凭证

#### 方式 A：获取 Cookie（推荐）

1. 在浏览器中登录目标网站
2. 按 `F12` 打开开发者工具
3. 点击 `Application` 标签
4. 左侧找到 `Cookies` → 点击你的网站
5. 复制 Cookie 信息（至少需要 `name` 和 `value`）

**快速复制格式**：

```json
[
  {
    "name": "这里填 Cookie 名称",
    "value": "这里填 Cookie 值",
    "domain": ".example.com"
  }
]
```

**常见 Cookie 名称**：
- `session`, `sessionid`, `PHPSESSID`
- `auth_token`, `access_token`, `jwt`
- `user_session`, `_session`

#### 方式 B：找到用户数据目录

**Windows (Chrome)**：
```
C:\Users\你的用户名\AppData\Local\Google\Chrome\User Data
```

**Windows (Edge)**：
```
C:\Users\你的用户名\AppData\Local\Microsoft\Edge\User Data
```

**注意**：使用前需要关闭浏览器！

#### 方式 C：准备手动登录

不需要准备，直接进入下一步。

### 步骤 3：执行克隆

#### 使用 Cookie 方式

```
请克隆 https://example.com/dashboard，使用 cookies：
[
  {
    "name": "session_id",
    "value": "你的Cookie值",
    "domain": ".example.com"
  }
]
```

#### 使用用户数据目录方式

```
请克隆 https://example.com/dashboard，使用用户数据目录：
C:\Users\jiangjj\AppData\Local\Google\Chrome\User Data
```

#### 使用手动登录方式

```
请克隆 https://example.com/login，使用非无头模式，等待 60000 毫秒
```

然后在打开的浏览器窗口中手动登录。

## 📝 完整示例

### 示例 1：克隆 GitHub 私有仓库

**第 1 步**：在浏览器中登录 GitHub

**第 2 步**：获取 Cookie
- 按 `F12`
- `Application` → `Cookies` → `https://github.com`
- 找到 `user_session` Cookie
- 复制它的值

**第 3 步**：执行克隆

```
请克隆 https://github.com/myname/private-repo，使用 cookies：
[
  {
    "name": "user_session",
    "value": "这里粘贴你复制的值",
    "domain": ".github.com",
    "secure": true,
    "httpOnly": true
  }
]
```

### 示例 2：克隆企业内网

**第 1 步**：确认已在 Chrome 中登录内网

**第 2 步**：关闭 Chrome 浏览器（完全关闭）

**第 3 步**：执行克隆

```
请克隆 https://intranet.company.com/dashboard，使用用户数据目录：
C:\Users\jiangjj\AppData\Local\Google\Chrome\User Data
```

### 示例 3：克隆有验证码的网站

**第 1 步**：准备好账号密码

**第 2 步**：执行克隆

```
请克隆 https://example.com/login，使用非无头模式，等待 120000 毫秒
```

**第 3 步**：在打开的浏览器窗口中
1. 输入账号密码
2. 输入验证码
3. 登录成功
4. 等待工具自动克隆

## 🔧 常见问题

### Q1：Cookie 在哪里找？

**A**：按 `F12` → `Application` → `Cookies` → 选择你的网站

### Q2：需要复制所有 Cookie 吗？

**A**：建议复制所有 Cookie，特别是包含 `session`、`token`、`auth` 的。

### Q3：Cookie 会过期吗？

**A**：会的。如果克隆失败，重新获取最新的 Cookie。

### Q4：用户数据目录在哪？

**A**：
- Chrome: `C:\Users\你的用户名\AppData\Local\Google\Chrome\User Data`
- Edge: `C:\Users\你的用户名\AppData\Local\Microsoft\Edge\User Data`

### Q5：使用用户数据目录安全吗？

**A**：安全。工具只读取登录状态，不会修改你的浏览器数据。

### Q6：非无头模式是什么意思？

**A**：就是显示浏览器窗口，你可以看到并操作浏览器。

### Q7：等待时间设置多少合适？

**A**：
- 简单页面：3000-5000 毫秒
- 复杂页面：8000-10000 毫秒
- 手动登录：60000-120000 毫秒（1-2 分钟）

### Q8：克隆失败怎么办？

**A**：
1. 检查 Cookie 是否正确
2. 增加等待时间
3. 使用非无头模式查看问题
4. 尝试其他登录方式

## 💡 实用技巧

### 技巧 1：快速测试 Cookie 是否有效

```
请克隆 https://example.com/dashboard，使用非无头模式，使用 cookies：[...]
```

这样可以看到浏览器窗口，确认是否成功登录。

### 技巧 2：批量克隆多个页面

获取一次 Cookie，可以克隆多个页面：

```
请克隆 https://example.com/page1，使用 cookies：[...]
请克隆 https://example.com/page2，使用 cookies：[...]
请克隆 https://example.com/page3，使用 cookies：[...]
```

### 技巧 3：保存常用 Cookie

将常用网站的 Cookie 保存到文本文件（注意安全！）：

```
cookies-github.json
cookies-company.json
```

使用时直接复制粘贴。

### 技巧 4：使用浏览器扩展快速导出

安装 "EditThisCookie" 或 "Cookie-Editor" 扩展：
1. 点击扩展图标
2. 点击"Export"
3. 选择 JSON 格式
4. 直接粘贴使用

1. **不要分享 Cookie**：Cookie 相当于你的登录密码
2. **定期更新**：Cookie 会过期，需要重新获取
3. **注意权限**：只克隆你有权访问的内容
4. **遵守法律**：不要用于非法用途
