# 更新日志

## v2.1.0 - 2025-12-31

### 🎉 新增功能：支持克隆需要登录的网站

#### 新增参数

1. **cookies** (可选)
   - 类型：`Array<Cookie>`
   - 说明：设置 Cookie 数组，用于访问需要登录的页面
   - 示例：
   ```json
   [
     {
       "name": "session_id",
       "value": "abc123",
       "domain": ".example.com"
     }
   ]
   ```

2. **userDataDir** (可选)
   - 类型：`string`
   - 说明：指定浏览器用户数据目录路径，保持登录状态
   - 示例：`C:\Users\xxx\AppData\Local\Google\Chrome\User Data`
   - 注意：使用前需要关闭浏览器

3. **headless** (可选)
   - 类型：`boolean`
   - 默认值：`true`
   - 说明：是否使用无头模式
   - 用途：设为 `false` 可以看到浏览器窗口，方便手动登录

### 📖 使用方法

#### 方法 1：使用 Cookie（推荐）

```
请克隆 https://example.com/dashboard，使用 cookies：
[
  {
    "name": "session_id",
    "value": "your_token",
    "domain": ".example.com"
  }
]
```

#### 方法 2：使用用户数据目录

```
请克隆 https://example.com/dashboard，使用用户数据目录：
C:\Users\jiangjj\AppData\Local\Google\Chrome\User Data
```

#### 方法 3：手动登录

```
请克隆 https://example.com/login，使用非无头模式，等待 60000 毫秒
```

### 🎯 适用场景

- ✅ GitHub 私有仓库
- ✅ 企业内网系统
- ✅ 需要登录的后台管理系统
- ✅ 会员专属页面
- ✅ 需要验证码的网站（使用非无头模式）

### ⚠️ 注意事项

1. **Cookie 安全**
   - Cookie 包含登录凭证，不要分享给他人
   - 使用完毕后建议删除 Cookie 记录

2. **用户数据目录**
   - 使用前必须完全关闭浏览器（包括后台进程）
   - 工具只读取登录状态，不会修改浏览器数据

3. **非无头模式**
   - 需要足够的等待时间完成登录
   - 适合需要手动输入验证码的场景

### 📊 性能影响

- Cookie 方式：无额外性能开销
- 用户数据目录：启动时间略有增加（+1-2秒）
- 非无头模式：需要渲染浏览器窗口（+2-3秒）
