## 基础示例

### 示例 1：克隆公开网站（保存到桌面）

```
请使用 clone_webpage 工具克隆 https://example.com
```

**结果**：
- 文件保存到桌面
- 文件夹名：`example_com_2025-12-31T10-30-00`
- 包含 `index.html` 和图片文件

### 示例 2：克隆到指定目录

```
请克隆 https://example.com 到 D:\websites\example 目录
```

### 示例 3：不下载图片（保留原链接）

```
请克隆 https://example.com，不下载图片
```

**用途**：
- 快速预览页面结构
- 减少下载时间
- 节省磁盘空间

### 示例 4：增加等待时间（慢速网站）

```
请克隆 https://slow-website.com，等待 10000 毫秒
```

**适用于**：
- 加载慢的网站
- 有大量动态内容的页面
- 懒加载图片较多的页面

### 示例 5：自定义视口大小

```
请克隆 https://example.com，使用 1366x768 的视口
```

**常用分辨率**：
- 桌面：`1920x1080`（默认）
- 笔记本：`1366x768`
- 平板：`768x1024`
- 手机：`375x667`

## 登录网站示例

### 示例 6：使用 Cookie 克隆（推荐）

```
请克隆 https://example.com/dashboard，使用以下 cookies：
[
  {
    "name": "session_id",
    "value": "abc123xyz789",
    "domain": ".example.com"
  },
  {
    "name": "auth_token",
    "value": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "domain": ".example.com"
  }
]
```

**如何获取 Cookie**：
1. 登录目标网站
2. 按 `F12` 打开开发者工具
3. 切换到 `Application` → `Cookies`
4. 复制需要的 Cookie

详细说明：[获取Cookie的方法.md](./获取Cookie的方法.md)

### 示例 7：使用浏览器用户数据目录

```
请克隆 https://example.com/dashboard，使用用户数据目录：
C:\Users\YourUsername\AppData\Local\Google\Chrome\User Data
```

**注意**：
- 使用前必须关闭 Chrome 浏览器
- 会使用浏览器中的所有登录状态

**常见路径**：

Windows (Chrome):
```
C:\Users\你的用户名\AppData\Local\Google\Chrome\User Data
```

Windows (Edge):
```
C:\Users\你的用户名\AppData\Local\Microsoft\Edge\User Data
```

macOS (Chrome):
```
~/Library/Application Support/Google/Chrome
```

### 示例 8：手动登录模式（非无头）

```
请克隆 https://example.com/login，使用非无头模式，等待 60000 毫秒
```

**操作流程**：
1. 浏览器窗口会打开
2. 在 60 秒内手动登录
3. 登录完成后，工具自动克隆页面

**适用场景**：
- 需要输入验证码
- 双因素认证（2FA）
- 复杂的登录流程

## 参数组合建议

### 快速预览（不下载图片）

```json
{
  "url": "https://example.com",
  "downloadImages": false,
  "waitTime": 2000
}
```

**优点**：
- 速度快
- 节省空间
- 适合快速查看布局

### 完整克隆（包含所有资源）

```json
{
  "url": "https://example.com",
  "downloadImages": true,
  "waitTime": 5000
}
```

**优点**：
- 完整保存
- 离线可用
- 保持目录结构

### 调试模式（可见浏览器）

```json
{
  "url": "https://example.com",
  "headless": false,
  "waitTime": 10000
}
```

**优点**：
- 可以看到加载过程
- 方便调试
- 可以手动交互

### 生产模式（自动化）

```json
{
  "url": "https://example.com",
  "outputDir": "D:\\output",
  "downloadImages": true,
  "waitTime": 5000,
  "headless": true,
  "cookies": [...]
}
```

**优点**：
- 完全自动化
- 适合批量处理
- 可以脚本化

## 性能优化建议

### 1. 不下载图片（最快）

```
downloadImages: false
```

**速度提升**：50-80%

### 2. 减少等待时间

```
waitTime: 2000  // 简单页面
waitTime: 5000  // 普通页面（默认）
waitTime: 10000 // 复杂页面
```

### 3. 使用较小的视口

```
viewport: { width: 1366, height: 768 }
```

**优点**：
- 渲染更快
- 占用内存更少

## 最佳实践

### 1. 先测试后批量

```
// 第一步：测试单个页面
请克隆 https://example.com/page1，使用非无头模式

// 第二步：确认参数后批量克隆
请克隆 https://example.com/page1 到 D:\output\page1
请克隆 https://example.com/page2 到 D:\output\page2
请克隆 https://example.com/page3 到 D:\output\page3
```

### 2. 根据网站类型调整参数

**静态网站**：
```json
{
  "waitTime": 2000,
  "downloadImages": true
}
```

**SPA 应用**：
```json
{
  "waitTime": 8000,
  "downloadImages": true
}
```

**需要登录**：
```json
{
  "cookies": [...],
  "waitTime": 5000
}
```

### 3. 合理使用输出目录

```
// 按网站组织
D:\clones\example.com\
D:\clones\github.com\

// 按项目组织
D:\projects\project1\clones\
D:\projects\project2\clones\

// 按日期组织
D:\clones\2025-12-31\
```

## 总结

| 场景 | 推荐配置 |
|------|---------|
| **快速预览** | `downloadImages: false`, `waitTime: 2000` |
| **完整克隆** | `downloadImages: true`, `waitTime: 5000` |
| **需要登录** | `cookies: [...]` 或 `userDataDir: "..."` |
| **调试问题** | `headless: false`, `waitTime: 10000` |
| **SPA 应用** | `waitTime: 8000+` |
| **移动端** | `viewport: { width: 375, height: 667 }` |
